# 정비 작업 안전 - 잠금·표지(LOTO) 절차

> 가상 매뉴얼 (포트폴리오 데모용). 모든 설비 공통.

## 개요
회전체·가열·전기 설비를 점검하거나 수리할 때 예기치 않은 기동과 에너지 방출을 막기 위한 절차다.
설비 점검, 노즐 분리, 베어링 교체, 밸브 정비 전에 반드시 수행한다.

## 적용 대상
- 배합기 임펠러·베어링 점검, 충진기 스타휠·노즐 작업, 탱크 밸브·재킷 배관 정비
- 운전 중 퍼지·세척 기능만 사용하는 경우는 제외

## 절차
1. 작업 전 관련 운전자와 생산 담당자에게 정지 사실을 알린다.
2. 정상 정지 절차로 설비를 정지한다.
3. 주전원 차단기를 내리고 개인 자물쇠와 표지(작업자 이름, 일시)를 단다.
4. 스팀·압축공기·원료 배관의 차단밸브를 잠그고 잔압을 빼낸다.
5. 기동 버튼을 눌러 기동되지 않는 것을 확인한다 (제로 에너지 확인).
6. 작업 후 공구와 인원을 철수하고, 자물쇠는 단 사람만 해제한다.

## 안전 주의사항
- 다른 사람의 자물쇠를 대신 해제하지 않는다.
- 교대 시에는 인계자가 자물쇠를 달고 나서 이전 작업자가 해제한다.
- 고온 설비는 표면 온도가 50C 이하로 내려간 뒤 작업한다.

## 에스컬레이션 기준
- 에너지 차단이 확인되지 않으면 작업을 시작하지 않고 설비팀장에게 보고한다.
